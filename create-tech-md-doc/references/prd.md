# PRD 增强（--prd）

拉取步骤、wiki 可用性判断与通用 `prd_context` 字段见 `references/prd-fetch.md`。任一步失败都回退纯 diff 流程，元信息写「PRD 增强已跳过」。

技术方案不需要额外字段，通用 `prd_context` 用于模块 1 需求背景与模块 7 数据链路。

## PRD 对齐校验

PRD 功能点与 diff 实现做语义对齐，在模块 8 输出两张清单：

- **对齐缺口**：PRD 有、代码里找不到实现的功能点；
- **实现超出 PRD**：代码里有、PRD 没提到的行为。

匹配不确定的不算缺口，标「待人工核对」。
