# diff 采集：技术方案的映射与抽取规则

基线、分层过滤命令、排除与巨量兜底、通用抽取规则见 `references/diff-collection-common.md`。本文件只写技术方案特有的部分。

## 层 → 事实类别

技术方案的章节由项目模板决定（见 SKILL.md Step 3）。采集时按下表归类事实，填充时放进模板里**含义对应**的章节；模板里没有对应章节的事实不擅自加章节，在交付摘要里列出。

| 层 | 事实类别 |
|---|---|
| 接口入口 | 接口（路径、方法、入参 / 返回） |
| 业务逻辑 | 详细方案、影响范围 |
| 数据结构 | 字段变更、DB 变更 |
| SQL 脚本 | 中间件变更：DB |
| 配置 | 中间件变更：配置 |
| 构建文件 | 依赖变更 |
| 定时任务 | 定时任务变更 |
| 消息 | 消息协议（topic、消息体） |

## 特有抽取规则

- **接口**：路径 + 方法 + 入参 / 返回类型；DTO / VO 新增字段 → 字段变更。
- **Service 方法**：签名 + 一句话职责（从方法名 / 注释推断，不臆造）。
- **DDL 表名**：进数据链路 / 数据评审类章节（模板有的话）。
