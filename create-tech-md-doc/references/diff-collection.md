## 特有抽取规则

- **接口**：路径 + 方法 + 入参 / 返回类型；DTO / VO 新增字段 → 字段变更示例。
- **Service 方法**：签名 + 一句话职责（从方法名 / 注释推断，不臆造）。
- **DDL 表名**：进模块 7 数据链路。
