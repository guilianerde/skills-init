# PRD 增强（--prd）

拉取步骤、wiki 可用性判断与通用 `prd_context` 字段见 `references/prd-fetch.md`。任一步失败都回退纯 diff 流程，元信息写「PRD 增强已跳过」。

上线方案在通用字段之外再抽取：

- `grayRelease`：灰度 / 开关描述（灰度类章节）
- `verifyScenarios`：业务验证场景（上线后验证类章节）

## PRD 对齐校验

PRD 功能点与 diff 实现做语义对齐，在回滚 / 止损类章节追加两张清单（模板没有这类章节时放在文末「PRD 对齐」一节，并在交付摘要里说明）：

- **对齐缺口**：PRD 有、代码里找不到实现的功能点；
- **实现超出 PRD**：代码里有、PRD 没提到的行为。

匹配不确定的不算缺口，标「待人工核对」。
