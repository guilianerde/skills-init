# 交付模板

F7 / B5 交付时按此输出。

```
# 开发交付 — <需求或缺陷简述>

## 结果
<一两句话：做成了什么；有无未完成项>

## 改动
| 文件 | 改动说明 |
|---|---|

## 验证
- 构建：<命令> → <通过 / 失败 / 未运行（原因）>
- 测试：<命令> → <通过 n 个 / 失败 / 未运行（原因）>；新增测试：<列表>
- 未验证项：<需要用户在什么环境怎么验证>

## 根因（仅缺陷修复）
<证据链：现象 → 出错位置 → 原因>

## 配置清单
| key | 位置 | 用途 | 建议默认值 | 需下发环境 |
|---|---|---|---|---|

## SQL 脚本（未执行）
<文件路径或脚本内容；无则写「无」>

## 自审
<project-review 结论摘要；遗留的 MEDIUM / LOW>

## 范围外发现
<顺带看到但本次未处理的问题>

## 建议下一步
<commit message 建议 / 文档 / DocNexus 沉淀>
```

> 小改动可以压缩成「改动 + 验证 + 下一步」三段；但验证结果必须如实。
