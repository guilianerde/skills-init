WORKFLOW-RUN / LOAN-SERVICE

接入已有文档仓库

适用于 loan-service 已下载到本地、团队独立文档仓库已有数据的情况。已有文档仓库中的项目名为 loan-service。

以下步骤假设本地 loan-service/workflow-run/ 没有需要保留的数据。把示例路径和仓库地址替换为实际值，并确认有仓库访问权限。

1. 接入仓库

安装命令程序

本机已经全局安装过 workflow-run 时，跳过安装命令。

npm install -g @rowansenne/workflow-run
workflow-run --version

进入业务项目

将路径替换为本机的项目路径。

cd /path/to/loan-service

接入已有文档仓库

将地址替换为团队的文档仓库地址。仓库会接入到项目下的 workflow-run/。

workflow-run docs-repo <文档仓库地址>
如果提示本地文件冲突，先保留并检查这些文件，处理冲突后再重新接入。

2. 项目初始化

初始化项目环境

安装所有环境的 skills、接入 CodeGraph，数据库暂时跳过。

workflow-run --envs all --skip-db --yes --with-codegraph

检查项目名

workflow-run docs-repo

已有文档仓库中的项目名是 loan-service。如果输出的项目名已经是 loan-service，无需修改；如果未配置，执行：

workflow-run docs-repo --project loan-service

验证并查看文档

workflow-run doctor --offline
workflow-run view --open

日常同步团队文档

在项目根目录执行，先检查本地改动，再拉取更新。

git -C workflow-run status
git -C workflow-run pull
